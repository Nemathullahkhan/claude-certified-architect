> **How to use this template:** copy this file to `wrong-answer-<scenario-slug>.md` (e.g. `wrong-answer-customer-support-agent.md`) the first time you take a mock test for a scenario. Log every missed question here with the **why**, not just the correct answer — the goal is to catch *recurring patterns* in your mistakes, not to memorize individual questions. This file is personal to your own attempts; it's not meant to carry anyone else's history.

**Problem-category legend** — start with these common exam failure axes (drawn from patterns that tend to recur across scenarios), rename/add your own as they emerge, and optionally cross-reference a `decision-framework.md` if you build one:

- 🔒 **Safety/Financial/Compliance** → deterministic gate/hook, never system prompt wording
- 🧠 **Reasoning/Sequencing Quality** → few-shot examples
- 🌀 **Open-ended/Variable Quality** → self-critique / reflection stage
- ⚡ **Efficiency/Latency** → smallest fix to how existing tools are used
- 🔧 **Technique Already Locked by Stem** → stay inside the technique the stem already committed to (watch for both inclusion — "add X" — and exclusion — "not through Y" — phrasing)
- 🆕 **New pattern** → tag a miss you can't yet categorize; promote it to a named category once it recurs
